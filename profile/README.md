# RoboTask

> RoboTask keeps triggered jobs on one Windows desk: open the task scheduler, pin the action list, and leave the trigger set on the same desktop jobs.

---

## Session Card

| Slice | What you do in RoboTask | What remains |
|-------|-------------------------|--------------|
| Arrival | Open RoboTask and name today's desktop jobs | A titled job |
| Focus | Keep only live actions on RoboTask action list | A short action list |
| Clock | Open RoboTask task scheduler for that job | A clock note |
| Check | Read RoboTask trigger set before a large change | A confirmed set |
| Handoff | Mark finished jobs inside RoboTask | A note for the next visit |

## Four Beats

1. **Name the job.** Give the RoboTask desktop jobs a short title before you trust a loose note.
2. **Pin the live actions.** Keep current work on RoboTask action list and leave unused jobs aside.
3. **Read the clock.** Open RoboTask task scheduler before you move a trigger that already has a job.
4. **Check the triggers.** Read RoboTask trigger set before you archive a job.
5. **Keep the pair.** Leave actions and triggers on the same RoboTask desktop jobs.
6. **Leave the clock ready.** Keep the trigger aligned with RoboTask action list.
7. **Close the loop.** Clear finished jobs so the next RoboTask visit does not start with a search.

## First Questions

**Does RoboTask replace every other program?**
No. RoboTask sits beside the clock, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate RoboTask profile.

**What should a new user try first?**
One small RoboTask action list today, then the same trigger set tomorrow.

**Does the trigger set leave the desktop jobs?**
No. RoboTask trigger set stays with RoboTask action list on that job.

**Is RoboTask only for a finished schedule?**
No. RoboTask can hold a single action while the rest of the clock stays off the board.

**Does the clock need a second file for the trigger?**
No. RoboTask keeps the action list and the trigger set on these desktop jobs.

## Field Note

RoboTask is easier to trust when the desktop jobs stay smaller than the folder they came from. A named job shows what is active, the action pins show what will fire today, and the closing note tells the next person which trigger changed.

The same loop fits a single action, a short trigger, or a desk shared by two people. Open the last RoboTask desktop jobs, finish one action list, and leave fewer loose notes than you found.

A review should not have to guess which trigger belongs to the open job. Keep that pair together inside RoboTask.

## One Real Pass

Pick a job that already has a name. Open it in RoboTask, keep only those actions on the list, and finish one trigger set you can see.

If the pass feels crowded, the set is too wide. Drop anything that belongs to a different clock and leave it out of these RoboTask desktop jobs.
